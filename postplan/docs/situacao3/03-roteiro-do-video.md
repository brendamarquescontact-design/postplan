# Roteiro do vídeo (meta: 5 minutos)

Grave a tela com o sistema aberto (OBS, Loom, ou o gravador do celular/PC) e narre com a sua voz.
**Atenção:** o enunciado da Situação 2 pede vídeo narrado de *pelo menos* 5 min, e o da Situação 3 pede *até* 5 min. Confirme com seu tutor; 5 minutos exatos atende às duas leituras.

| Tempo | Mostrar | Falar (adapte com suas palavras) |
|---|---|---|
| 0:00–0:30 | Tela de login | “Oi, eu sou [seu nome], RGM [seu RGM]. Este é o PostPlan, um planejador de conteúdo para criadores, feito em Python com Flask e banco SQLite.” |
| 0:30–1:00 | Cadastro com senha curta → erro → cadastro correto | “Aqui a validação mostra uma mensagem clara e mantém o que foi digitado.” |
| 1:00–1:40 | Pilares → criar 2 pilares | “Pilares são os temas do perfil. Cada um tem cor própria.” |
| 1:40–2:30 | Novo post (primeiro com erro, depois correto) | “Título, plataforma, pilar, data e roteiro. Se eu publicar sem data, o sistema avisa.” |
| 2:30–3:15 | Lista: filtros, avançar etapa, editar, excluir com confirmação | “O funil vai de ideia a publicado. A exclusão pede confirmação para evitar erros.” |
| 3:15–3:45 | Painel e calendário | “O painel resume quantos posts estão em cada etapa; o calendário agrupa por dia.” |
| 3:45–4:15 | Celular (ou janela estreita) | “A interface é responsiva: a tabela vira cartões.” |
| 4:15–5:00 | **Mudanças feitas após os testes dos colegas** (sua seção 3 do laudo) + terminal com `pytest` | “Os testes automatizados são 41. Depois do feedback de cinco colegas, corrigi: [liste as correções reais]. Obrigada!” |

Dicas: feche abas pessoais, aumente o zoom do navegador para 110%, ensaie uma vez e fale devagar.
